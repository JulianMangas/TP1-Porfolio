# Portfolio Personal

Portfolio personal hecho para la Actividad Práctica N° 1 de Programación Web. Tiene una página de inicio, una de proyectos y una de contacto.

## Tecnologías utilizadas

- HTML5
- Bootstrap 5.3
- CSS
- JavaScript

## Cómo verlo localmente

1. Clonar el repositorio:
   ```
   git clone https://github.com/Julymangas/portfolio.git
   ```
2. Abrir el archivo `index.html` en el navegador.
